# FX Digital

Website statis 6 halaman dengan CSS dan JavaScript terpisah.

- index.html — Beranda
- fx-web.html — FX Web
- fx-docs.html — FX Docs
- fx-tech.html — FX Tech
- fx-gaming.html — FX Gaming
- kontak.html — Kontak & Maps
- assets/css/style.css — CSS responsif
- assets/js/config.js — Konfigurasi kontak
- assets/js/main.js — Navigasi dan tombol kontak

## Preview lokal

Jalankan `python3 -m http.server 8000` lalu buka http://localhost:8000.
